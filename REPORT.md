# One-page Report — Camera Degradation Health Score

## 1. Problem
A forward ADAS camera can become temporarily unreliable because of blur, glare/over-exposure, contamination, noise, or exposure failures. A perception stack should distinguish **camera health** from ordinary detector uncertainty so that downstream logic knows when visual evidence itself is degraded.

## 2. Method
We use a deliberately lightweight pipeline suitable for a 120-minute lab:

**RGB frame → degradation injection → health metrics → optional YOLOv8n proxy → health state → fallback recommendation**

Degradations: Gaussian blur (k=5/11/21), strong local glare, salt-and-pepper noise.

Health signals:
- Laplacian variance (sharpness proxy)
- saturation ratio (clipping/glare proxy)
- entropy
- Canny edge retention
- optional YOLO detection count and mean confidence

The demo health score is a heuristic combination used only for this experiment. It is **not a calibrated safety score**.

## 3. Benchmark
The default benchmark is deterministic synthetic data and needs no external dataset. Run:

```bash
pip install -r requirements.txt
python src/run_demo.py
```

This produces `results/metrics.csv`, degraded frames, and plots. To add a detector proxy:

```bash
pip install ultralytics
python src/run_demo.py --yolo
```

**Evidence rule:** report the values generated by your run. Do not describe detector confidence as mAP or recall; those require labeled ground truth.

## 4. Failure case
Strong glare can destroy useful pixels locally while a global sharpness metric remains deceptively acceptable because edges survive elsewhere. Therefore **Laplacian variance alone is insufficient**. Saturation/exposure evidence must be included, and ideally camera ISP metadata such as exposure time, gain, shutter and sensor diagnostics.

## 5. Engineering decision
Prototype rule:

**health < 0.40 for 3 consecutive frames → camera DEGRADED**

Then:
1. record the event and camera/ISP metadata;
2. down-weight camera evidence in sensor fusion;
3. request a safer operating mode;
4. where the vehicle architecture supports it, rely more on independent Radar/LiDAR evidence.

The 0.40 threshold and 3-frame persistence are demonstration choices requiring calibration and safety validation before production use.

## What is ours vs external
All CSV/plot values are generated by this repository. Literature is used only to motivate corruption robustness and sensor-health monitoring. No external benchmark number is copied into our experimental results.
